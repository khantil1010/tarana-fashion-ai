Tarana Fashion AI is a personal research application designed to organize, analyze, and search visual fashion content using artificial intelligence.

What is Tarana Fashion AI?

Tarana Fashion AI is being developed as a personal fashion research and visual analysis tool. It uses authorized Pinterest data to help organize fashion references and extract structured information from visual content.

Visual Analysis

Analyze fashion imagery to identify garments, colors, fabrics, patterns, silhouettes, styling and other visual attributes.

Semantic Search

Search a personal fashion knowledge base using natural language rather than relying only on keywords.

Trend Research

Organize fashion observations over time and use them for personal research into seasonal and emerging fashion patterns.

Use of Pinterest Data

The application is intended for personal use and will access Pinterest data only through authorized Pinterest API permissions.


Pinterest data is used to organize and analyze fashion references for personal research. The application is not intended to impersonate Pinterest or represent itself as an official Pinterest product.


The application will request only the Pinterest permissions required for its functionality.
